# Music Player

A modern and interactive Music Player built using **HTML, CSS, and JavaScript**. The application provides essential music playback controls, playlist management, and a clean user interface for an enjoyable listening experience.

## Features

* Play and pause music
* Next and previous track controls
* Shuffle playlist functionality
* Dynamic playlist rendering
* Album artwork display
* Song title and artist information
* Responsive and user-friendly design

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## Getting Started

### Clone the Repository

```bash
git clone <https://github.com/SharathChandra-dev/Music-Player>
cd Music-Player-master
```

### Run the Application

No installation is required.

#### Option 1: Open Directly

Open `index.html` in your preferred web browser.

#### Option 2: Run a Local Server (Recommended)

```bash
python3 -m http.server 5500
```

Then open:

```text
http://localhost:5500
```

## How It Works

The application maintains a playlist of songs and allows users to:

* Play and pause tracks
* Navigate between songs
* Shuffle the playlist order
* View current song details and album artwork
* Manage playback through intuitive controls
