# 🎵 Music Player App

## Overview

The **Music Player App** is a responsive web-based application built using **HTML, CSS, and JavaScript**. It provides an intuitive interface for playing and managing a playlist of songs with essential music controls like play, pause, skip, shuffle, and playlist management.

This project demonstrates core JavaScript concepts such as DOM manipulation, event handling, array methods, and dynamic UI rendering.

## ✨ Features

### 🎧 Player Controls

* Play and Pause songs
* Next and Previous track navigation
* Shuffle playlist functionality

### 📋 Playlist Management

* View song title, artist, and duration
* Click to play any song
* Delete unwanted songs from playlist
* Reset playlist when empty

## 🚀 Getting Started

### Clone the Repository

```bash id="clone001"
git clone https://github.com/SharathChandra-dev/Music-Player.git
cd Music-Player
```

### Run the App

#### Option 1: Open Directly

Open `index.html` in your browser.

#### Option 2: Local Server (Recommended)

```bash id="server001"
python3 -m http.server 5500
```

Then open:

```text id="open001"
http://localhost:5500
```

## 🎯 How It Works

* Playlist is stored as an array of song objects
* JavaScript handles playback logic and UI updates
* DOM updates reflect current song and playlist state
* Shuffle randomly reorders the playlist
* User interactions trigger event listeners for controls
